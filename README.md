# ANT PRO packaging artwork

The [prepress review package](https://github.com/abusultan/antpro-desigin/releases/tag/prepress-tablet-qty-confirmed) contains 26 carton layouts, 26 front-only film designs, and factory reference templates.

Tablet carton quantities are 20 pieces for 13-inch and 5 pieces for 16-inch, for both TPU and 9H. The 16-inch film cut size and production dielines are pending factory confirmation. This package is for review before printing.
